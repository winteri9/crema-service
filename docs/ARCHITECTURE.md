# <Проект> — архитектура

Карта кода и принятые решения. Обновлять по ходу, а не в конце.
Принципы, на которых стоит проект — `~/.dsh/rules/architecture.md`; здесь только конкретика проекта.
Что дальше и как переделать под клиента — `HANDOFF.md`.

## Дерево

```
src/
  data/
    site.ts        факты: SITE, CONTACTS, NAV, SOCIALS
    services.ts    Service + SERVICES (пусто до плана)
  components/
    sections/      Hero → Services → Contact (порядок в pages/index.astro)
  layouts/
    BaseLayout.astro  <html>, <head>, мета, слот
  pages/
    index.astro    порядок секций — здесь и только здесь
  lib/
    format.ts      fmt, plural, perMeter, priceLabel, nb (без Intl — детерминированно)
    images.ts      localPhoto (скачанные) + img/srcSet/hotImage (хотлинк) + атрибуция
  styles/
    tokens.css     цвет только здесь: примитивы + поверхности
    base.css       сброс и общее
tools/
  verify.mjs           оркестратор: одна команда на проверку
  contrast.mjs         WCAG-контраст пар из tokens.css
  shot.mjs             скриншоты через CDP, Chrome ищется сам
  predeploy-check.mjs  гейт перед выкладкой
  fetch_photos.py      фото из Unsplash + манифест атрибуции
assets/photos/         скачанные фото, photos.json
.claude/               settings.json (запреты), rules/, launch.json
```

## Решения и даты

| Дата | Решение | Почему |
|---|---|---|
| 07.11.2026 | Astro, статика без UI-фреймворков | контентный сайт: ноль JS по умолчанию; Next — только при >2 связанных состояниях |
| 07.11.2026 | Данные в `src/data`, разметка без фактов | правка контента не касается вёрстки; типы ловят ошибку на сборке |
| 07.11.2026 | Цвет только в `tokens.css` + поверхности | смена палитры = правка примитивов, контраст проверяется машинно |
| 07.11.2026 | `fmt` без `Intl` | сервер и браузер обязаны давать одинаковую строку |
| 07.11.2026 | Фото: скачивание для hero, хотлинк для галерей | hero не должен зависеть от чужого CDN; галереи не должны весить в репозитории |
| 07.11.2026 | Порт предпросмотра 4321 + `--host 127.0.0.1` | на Windows без host сервер слушает только `::1` и проверки не достучатся |

## Состояние на `<html>`

<!-- Принцип 7: состояние объявляется классом, а скрытие до анимации — только под html.js -->

- `js` — JS работает. Скрытое до анимации прячется только под `html.js`.
- `reduce` — `prefers-reduced-motion: reduce`: ничего не движется само.

В шаблоне состояния нет: страница полностью статична. Проверено — скриншоты `desktop`, `no-js` и `reduce`
побайтово совпадают.

## Поверхности

<!-- Секция объявляет surface-*, семантика (--bg/--fg) переключается в tokens.css -->

| Поверхность | Фон | Где применяется |
|---|---|---|
| `surface-paper` | `--paper` `#FFFFFF` | основной фон, секции с текстом |
| `surface-mist` | `--mist` `#F1F2F4` | подложка, чередование блоков |
| `surface-ink` | `--ink` `#14161A` | тёмные акцентные секции |
| `surface-accent` | `--accent` `#17557F` | заявка, главный CTA-блок |

Пары контраста и их значения — в `HANDOFF.md` §2, проверка — `npm run contrast`.

## Проверки

```powershell
npm run verify          # типы + сборка + контраст + скриншоты + структура
npm run verify:fast     # без скриншотов
npm run predeploy       # строгий гейт: валит на TODO (перед выкладкой)
npm run photos -- "запрос" -n 5
```

| Инструмент | Что даёт | Состояние |
|---|---|---|
| `contrast.mjs` | WCAG-контраст пар из `tokens.css`, exit 1 при провале, `--list` для отчёта | работает, пары под нашу палитру |
| `shot.mjs` | скриншоты 1440/390, `--full --scroll --reduce --no-js --mobile --json`; **путь к Chrome параметризован** (`CHROME_PATH` → типовые пути → PATH) | работает на Windows без правок |
| `predeploy-check.mjs` | гейт: `TODO`, плейсхолдеры, `localhost`, пустое мета, битые ссылки, утечка ключа | работает; `--allow-todo` для шаблона |
| `verify.mjs` | всё перечисленное одной командой, скриншоты в `.cache/verify/` | работает, 9 проверок |
