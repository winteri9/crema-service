# Модель кофемашины: архитектура

Источник формы — `ref/hero.png` (фото 1). Габариты взяты по пропорциям кадра и
типовым размерам бытовых суперавтоматов: **240 × 340 × 440 мм** (Ш × В × Г),
низ на столе, фронт — золотая панель, справа паровой кран, сверху площадка
подогрева чашек.

Единицы в Blender — метры (0.24 × 0.44 × 0.34). Экспорт — GLB, Y-up, масштаб 1.

## Дерево объектов

```
Machine_Root                     пустышка в центре основания
├─ Shell                         пустышка, неподвижная оболочка
│  ├─ Body_Main                  корпус: скруглённый параллелепипед, фаска 4 мм
│  ├─ Panel_Left                 левая щека (съёмная)
│  ├─ Panel_Right                правая щека
│  ├─ Panel_Front                лицевая золотая панель с окнами
│  ├─ Panel_Top                  верхняя площадка подогрева
│  ├─ Grille_Top                 прутья площадки (3 шт.)
│  ├─ Base_Plinth                плинтус
│  └─ Badge                     шильдик
├─ Front                         передняя сборка
│  ├─ Control_Panel              стекло дисплея + рамка
│  ├─ Button_Left, Button_Right  кнопки (2)
│  ├─ Key_Row                    три клавиши
│  └─ Group_Head                 варочная группа (хром)
│     ├─ Group_Ring
│     ├─ Group_Spout             носик выдачи
│     └─ Portafilter             рожок с ручкой
├─ Internals
│  ├─ Brewing_Unit               заварочный блок (цилиндр + шток)
│  ├─ Boiler                     бойлер (медь)
│  ├─ Pump                       помпа
│  ├─ Water_Tank                 бак, съёмный, с ручкой
│  ├─ Bean_Hopper                контейнер для зёрен
│  │  ├─ Hopper_Body
│  │  ├─ Hopper_Lid
│  │  └─ Beans                   инстансы зёрен (80 шт.)
│  ├─ Grinder                    жернова (внутри бункера)
│  └─ Steam_Wand                 паровой кран (труба + клапан)
└─ Drip
   ├─ Drip_Tray                  поддон
   └─ Drip_Grate                 решётка
```

## Порядок разборки (без столкновений)

1. `Bean_Hopper` + `Hopper_Lid` — вверх на 0.26 м.
2. `Panel_Top`, `Grille_Top` — вверх на 0.12 м, затем в сторону.
3. `Panel_Left` / `Panel_Right` — в стороны по X на 0.22 м.
4. `Water_Tank` — влево-назад (−X, −Z), выезжает из паза.
5. `Drip_Tray` + `Drip_Grate` — вниз-вперёд (−Y, +Z).
6. `Panel_Front` — вперёд на 0.18 м (открывает нутро).
7. `Group_Head` + `Portafilter` — вперёд на 0.10 м.
8. `Brewing_Unit`, `Boiler`, `Pump`, `Grinder`, `Steam_Wand` — расходятся
   радиально из центра корпуса.

Каждый объект хранит исходную матрицу в `obj["rest_matrix"]` (16 float) и
`obj["explode_vector"]` (3 float) — сборка возвращает точные трансформы.

| Имя | Base | Metallic | Rough | Назначение |
| --- | --- | --- | --- | --- |
| M_Aluminium | #C9C4BC | 1.0 | 0.34 | корпус, щёки |
| M_Gold | #D8A24A | 1.0 | 0.16 | лицевая панель, плинтус |
| M_Chrome | #E8E4DC | 1.0 | 0.10 | группа, рожок, кран |
| M_Plastic_Dark | #16130F | 0.0 | 0.42 | основание, ручки, решётка |
| M_Plastic_Matte | #2A2622 | 0.0 | 0.62 | бак, бункер |
| M_Glass_Display | #0A0908 | 0.1 | 0.08 | дисплей |
| M_Copper | #A9663A | 1.0 | 0.38 | бойлер |
| M_Bean | #3A2414 | 0.0 | 0.55 | зёрна |

Без процедурных текстур: glTF их не несёт. Реализм — за счёт геометрии
(фаски 2–4 мм, зазоры 1.2 мм), roughness и студийного env на сайте.

## Экспорт

- `tools/blender/build.py` — сборка сцены, `--stage n`.
- `tools/blender/export.py` — все меши под `Machine_Root`, GLB + Draco
  выключен, материалы Principled, `export_apply=True`, `use_selection=False`.
- Результат: `public/model/machine.glb` (цель < 3 МБ), превью-рендер
  `pics/model-stage{n}.png` (EEVEE, 1600×1200, прозрачный фон).
- В браузере: `GLTFLoader` + DRACOLoader (не нужен), `OrbitControls`,
  разборка по `explode_vector` через GSAP, hover-подсветка через emissive
  слоя, подписи — DOM.

## Проверка

1. Рендер каждого этапа: силуэт, фаски, зазоры, отражения.
2. `gltf-transform inspect` — дерево, материалы, вес.
3. В браузере: 60 fps на 1440, корректная сборка (расхождение < 0.1 мм),
   консоль пустая.
