# <Проект> — сайт

Роутер проекта. Держать коротким: детали — в отдельных файлах, этот файл говорит, что читать и в каком порядке.
Базовые принципы унаследованы из `~/.dsh/rules/architecture.md` — не дублировать их здесь.

## Порядок чтения

1. `HANDOFF.md` — что дальше: как переделать под клиента, что не сделано, история
2. `plans/YYYY-MM-DD-<slug>.md` — что делаем, kill list, фазы `[ ] / [x]`
3. `docs/ARCHITECTURE.md` — карта кода и принятые решения
4. Этот файл — стек, структура, правила
5. `retrospectives/` — что уже поняли
6. `.claude/rules/` — правила проекта по домену (контент и дизайн, проверки)

## Стек

- Astro (static) → `dist/`. Зафиксировано: `astro 7.4.7`, `@astrojs/check 0.9.12`, `typescript 6.0.3`.
- Без UI-фреймворков и без библиотек анимации, пока не доказана необходимость.
- `npm run build` = `astro check && astro build`. Ошибка типов = нет сборки.
- `npm run dev`, `npm run photos` (Unsplash).
- **`npm run verify` обязателен перед каждой сдачей**: типы + сборка + контраст + скриншоты + структура.

## Структура

- `src/data/` — факты. `site.ts` (контакты, навигация, юрлицо, SEO), `services.ts`, дальше по проекту: `cases.ts`, `legal.ts`.
- `src/components/sections/` — секции главной, по файлу на блок. Порядок — в `src/pages/index.astro`.
- `src/layouts/BaseLayout.astro` — каркас документа.
- `src/styles/` — `tokens.css` (цвет только здесь), `base.css`.
- `tools/` — `fetch_photos.py` и инструменты проверки.
- `assets/photos/` — фото + `photos.json` с атрибуцией.
- `plans/`, `retrospectives/`, `docs/` — процесс и документация.

## Правила

1. **Нет факта — нет строки.** Не выдумывать цифры, отзывы, сроки, цены, кейсы. Источник каждого факта — в шапке файла данных.
2. **Цвет только из `tokens.css`.** Сырой `#hex` в компоненте — ошибка.
3. **Один блок макета = один файл секции.** Секция не импортирует другую секцию.
4. **Порядок секций — только в `index.astro`.**
5. **Без JS всё читается.** Скрытие до анимации — только под `html.js`, `reduce` отключает движение.
6. **Секреты только в `.env`.** Ключи не коммитить, в репозитории — `.env.example`.
7. **`git add` поимённо.** Никогда `git add .`.
8. **Деплой только по явной команде.**
9. **Сдавать со скриншотами** 1440 и 390 плюс `--reduce`. Открыть и посмотреть.
10. **Веху закрывать ретроспективой:** Задача · Как решали · Было → стало · Уроки · Открыто.
